# Market Alert PWA V2

Versão 2 do painel PWA com foco em usabilidade para iniciantes.

## Melhor hospedagem grátis
- Netlify: muito simples, plano grátis, HTTPS e deploy fácil.
- Cloudflare Pages: excelente para site estático e também grátis.
- GitHub Pages: grátis, mas costuma ser menos amigável para quem está só no celular.

## Recomendação prática
Se você está no celular agora, o melhor é usar Netlify ou Cloudflare Pages.

## Fluxo sugerido
1. Hospedar a pasta inteira.
2. Abrir o link no Chrome do celular.
3. Ativar notificações.
4. Instalar como app.
5. Depois evoluir para backend real.
